# Single-Page HTML CV

Este projeto é parte do roadmap.sh e consiste em criar um currículo em HTML de página única.

## Requisitos
- Estrutura semântica em HTML
- Seções: Educação, Experiência, Habilidades
- Meta tags essenciais para SEO
- Tags Open Graph para redes sociais
- Favicon configurado

## Como usar
Clone este repositório e abra o arquivo `index.html` em qualquer navegador.

git clone https://github.com/seu-usuario/single-page-html-cv
cd single-page-html-cv
